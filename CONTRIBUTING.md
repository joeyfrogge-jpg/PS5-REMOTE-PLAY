# Contributing to PS5-REMOTE-PLAY

Thank you for your interest in this independent Remote Play client.

## Principles

- This is **not** a Chiaki fork. Do not submit code copied or closely derived from Chiaki, chiaki-ng, or other existing clients.
- Prefer clean, readable implementations over clever micro-optimizations.
- Older hardware compatibility is a first-class goal. Any change that significantly raises minimum requirements should be discussed first.
- Keep the dependency surface small.

## Getting Started

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Open a pull request with a clear description of what and why

## Code Style

- Python: follow PEP 8, use type hints where practical
- C/C++ (future): modern C++17+, clear naming, no unnecessary templates

## Protocol Work

Protocol reverse-engineering contributions are welcome but must be original work. Document findings clearly so others can verify them independently.
